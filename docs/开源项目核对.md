# 开源项目核对（2026-11-05）

## 结论

有成熟度较高的相关项目，但未核实有“安装即用、完全复用用户现有 Chrome 会话、针对 QQ 客户端复制链接一键保存”的完全同款工具。项目说明中的支持与当前账户实测可用必须区分。

| 项目 | 查到的能力 | 与本需求的关系 |
|---|---|---|
| [go-music-dl](https://github.com/guohuiyuan/go-music-dl) | 官方 README：Mac 桌面、Web/TUI、QQ 单曲分享链接、扫码/Cookie 登录、歌单；GitHub API 当次核对约 5988 stars，最近推送 2026-11-04，AGPL-3.0 | 最值得优先试用的成品备选。如果网页捕获方案持续受限，可改为基于其本地接口做启动器；这会使用独立登录与后台进程。 |
| [musicdl](https://github.com/CharlesPikachu/musicdl) | 官方 README：Python 多平台、QQ 搜索下载、QQ 歌单解析，支持传入 QQ 登录 Cookie | 适合脚本二次开发；不是用户现有浏览器流程的一键替代。 |
| [cat-catch](https://github.com/xifangczy/cat-catch) | GitHub API 当次核对约 22784 stars、最近推送 2026-10-28、GPL-3.0；变更记录有自动下载和文件名定制 | 用户已经验证过的可行播放路径。功能通用，但完整流程仍需额外编排；本工具独立实现专用流程。 |

## 维护与可用性证据

- go-music-dl [README](https://github.com/guohuiyuan/go-music-dl/blob/main/README.md) 明确写出 QQ 下载需要有效 Cookie；QQ/微信登录和平台策略影响结果。
- [Issue #203](https://github.com/guohuiyuan/go-music-dl/issues/203)：有有效 Cookie、VIP 仍下载无效的反馈。此为问题反馈，不推断所有用户均不可用。
- [Issue #208](https://github.com/guohuiyuan/go-music-dl/issues/208)：QQ Cookie 错误反馈，需要具体链接复现。
- [musicdl 文档](https://github.com/CharlesPikachu/musicdl/blob/master/docs/Quickstart.md)：QQMusicClient 和歌单链接示例。
- [猫抓变更记录](https://github.com/xifangczy/cat-catch/blob/master/CHANGELOG.md)：自动下载、文件名定制与持续修复。

未安装或执行候选项目发布的二进制，也未复制 GPL/AGPL 项目源码。当前原型为独立实现；后续如嵌入第三方组件，另行核对具体版本许可证。
